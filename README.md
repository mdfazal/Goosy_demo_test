## To-Do List app

A no-build, vanilla HTML/CSS/JS to-do list. Open `index.html` in a browser.

- Add a task with the input box (Enter or **Add**)
- Tick the checkbox or click the task text to strike it off (click again to undo)
- **×** deletes a task; **Clear completed** removes all struck-off tasks
- Tasks are saved in your browser's localStorage
